# Experiment protocol

Record the design and orchestration revisions, generated inputs, tool and platform versions, constraints, command arguments, seeds, and resource limits. Preserve failed and interrupted runs. Archive logs, normalized metrics, and the locations and hashes of large artifacts.

Compare standard ORFS, deterministic recovery, LLM-assisted recovery, and LLM-assisted optimization under identical RTL, platform views, constraints, and resource budgets. Record attempts, tool time, model time and cost, engineering interventions, and success rate. Compare physical QoR only when each metric is measured using comparable inputs and units.

Keep timing coverage, setup, hold, DRC, LVS, equivalence, and artifact integrity as independent gates. Use passed, failed, blocked, and not checked. Record missing metrics as unavailable.
