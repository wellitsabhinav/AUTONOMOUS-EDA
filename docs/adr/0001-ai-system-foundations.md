# ADR 0001. AI system foundations

Proposed on 2026-11-13.

The local controller already has explicit stage dependencies, SQLite attempts, and artifact-validated checkpoints. The published bootstrap merged at `6a43937`. These decisions guide later slices and add no runtime dependency to Environment Doctor.

| Area | Decision and rationale |
| --- | --- |
| Orchestration | Start with a typed Python state machine and SQLite transition journal. Its finite workflow, fixed execution interfaces, and existing local persistence make explicit transitions adequate. LangGraph provides checkpointing and interrupts. Adopting it now would add a second workflow abstraction while controller dispatch would still need idempotency and recovery. Revisit if parallel graph coordination becomes a measured maintenance constraint. [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence) · [Interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts) |
| Retrieval storage | Keep experiment records authoritative in SQLite. Use a rebuildable SQLite FTS5 BM25 index and persist normalized vectors with their model and schema identifiers. Scan vectors after metadata filtering for the first corpus. Measure latency, relevance and update costs before adding approximate indexing or an external service. Check FTS5 availability on supported runtimes. [SQLite FTS5](https://www.sqlite.org/fts5.html) |
| MCP | Use the official Python SDK with local stdio and narrow read-only schemas. At implementation, verify the SDK release against the protocol revision, pin it as an optional dependency, and run a real subprocess integration test. Add Streamable HTTP only with a reviewed access-control design and interoperability tests. [MCP transport specification](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports) · [Official Python SDK](https://github.com/modelcontextprotocol/python-sdk) |
| Model gateway | Define a provider-independent structured interface. Start with a deterministic mock and an optional local endpoint adapter. Add one opt-in hosted adapter with consent and validated payloads. Centralize model routing, retries, context limits, redaction, and usage accounting in the gateway so physical runs can proceed independently. |
| Security and evidence | Keep proposal, authorization, execution, and evaluation boundaries explicit. Permissions bind to typed actions and immutable plan inputs. Use scoped paths and server capabilities, bounded execution, restricted subprocess environments, separate credentials, and secret-safe audit events. Treat descriptions, logs, and retrieved documents as untrusted data. Independent gate results require verified artifact references and applicable deterministic checks. [MCP security principles](https://modelcontextprotocol.io/specification/2026-07-28#security-and-trust-safety) |

Validate replay across interruption and duplicate dispatch, initial retrieval against BM25, real MCP discovery and invocation, provider failure without physical-state mutation, and negative authorization and injection cases. The Environment Doctor milestone adds offline environment validation ahead of these integrations.

Milestone 05 implements retrieval schema 1 in a separate SQLite database. FTS5 and exact cosine search share a source registry and evidence integrity checks. The first model uses a pinned MiniLM ONNX export with local CPU inference. Model changes rebuild the index transactionally. Schema changes can rebuild a fresh index from the registry. The [retrieval architecture](../RAG_ARCHITECTURE.md) describes the storage and ranking decisions, and the [benchmark](../RAG_BENCHMARK.md) records the measured tradeoffs.
