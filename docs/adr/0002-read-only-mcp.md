# ADR 0002 — Official Python MCP SDK over local stdio

**Status** Accepted for milestone 04.

Pin the official `mcp==2.3.0` SDK in the optional `mcp` extra. The release supports Python 3.10 and newer, which includes the repository's Python 3.11 and 3.12 test matrix. It ships `mcp-types==2.3.0` as a matching dependency. The 2.x SDK implements discovery at protocol `2026-07-28` and supports handshake-era peers. The integration exercises `2026-07-28` and `2025-11-25` over stdio. [SDK release](https://github.com/modelcontextprotocol/python-sdk/releases/tag/v2.3.0), [package metadata](https://pypi.org/project/mcp/2.3.0/), [protocol compatibility](https://github.com/modelcontextprotocol/python-sdk/blob/v2.3.0/docs/protocol-versions.md).

Use the SDK's low-level server and official `Client`. One fixed catalog provides Pydantic validation and JSON Schemas for each tool's input and structured output. The lower-level handlers let the service apply explicit authorization, error mapping, audit records, and deadlines while the SDK handles the wire protocol. The server advertises tools and returns evidence metadata through their typed outputs. The deterministic controller retains its dependency-free install. [Migration guide](https://github.com/modelcontextprotocol/python-sdk/blob/v2.3.0/docs/migration.md), [tool specification](https://modelcontextprotocol.io/specification/2026-07-28/server/tools).

Use the stdio transport's process boundary and keep stdout reserved for MCP. A process-isolated read worker captures only the recorded artifact inventory and calls the schema 1 API on the snapshot. Process termination bounds a cancelled parser or hash calculation even when it cannot cooperate. The trust model depends on the operator-owned allowlist and OS file permissions. The built-in client starts the installed executable directly. Network transports and server-selected executable commands are outside this integration. [Stdio specification](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/stdio), [MCP security guidance](https://modelcontextprotocol.io/docs/2026-07-28/tutorials/security/security_best_practices), [SDK advisories](https://github.com/modelcontextprotocol/python-sdk/security/advisories).
